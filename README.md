### !!THIS WILL LITERALLY LISTEN TO YOUR KEYSTROKES!!


This is necessary to count which keys are being pressed. The raw keypress data NEVER leaves your machine and this does NOT require an internet connection to use. The order of keypresses are NEVER stored so it is not possible to reverse what you typed. Although the site is hosted on https://harvest7777.github.io/heatmap/viewer for free use and I do NOT save or send the non-sensitive count and keymap data anywhere else, you can also just clone the repo and open the html file locally.
