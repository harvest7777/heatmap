!!THIS WILL LITERALLY LISTEN TO YOUR KEYSTROKES!!

This is necessary to count which keys are being pressed. Data NEVER leaves your machine and this does NOT require an internet connection to use. The order of keypresses are NEVER stored so it is not possible to reverse what you typed.

---

AI usage
Claude Opus 5.5 was used for the implementation. The design and requirements were human designed and reviewed. Unfiltered human design and Claude responses are in the commit history and markdown files. This README.md is entirely human written.
